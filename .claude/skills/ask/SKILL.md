# Ask - KB Question Answering

Ask the User Guide Agent questions about the Knowledge Base.

## Usage

```
/ask <your question>
```

## Example Questions

**Technology Recommendations**:
- `/ask What technology should I use for authentication?`
- `/ask Compare JWT vs session-based auth`
- `/ask What's the best database for my use case?`

**Implementation Guidance**:
- `/ask How does SSE streaming work?`
- `/ask Show me FastAPI authentication examples`
- `/ask How to implement real-time chat?`

**UI Patterns**:
- `/ask What does the chat interface look like?`
- `/ask Show me sidebar navigation layouts`
- `/ask How is the admin panel structured?`

**Project Examples**:
- `/ask Show me projects using PostgreSQL and FastAPI`
- `/ask What projects implement authentication?`
- `/ask Reference implementations for data streaming`

**Expertise**:
- `/ask Who knows Python?`
- `/ask Who has experience with React?`

---

The User Guide Agent will navigate the Knowledge Base and provide structured answers with code examples, architecture diagrams, and links to related documentation.
