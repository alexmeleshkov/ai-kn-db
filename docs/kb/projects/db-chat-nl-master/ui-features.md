# UI Features

> **Purpose**: Link to UI feature documentation in the shared KB.
> This file contains ONLY links. Layout and visual details are in `docs/kb/features/ui/`.

This project implements the following UI features:

## Chat Interface
Complete UI patterns: [chat-interface.md](../../features/ui/chat-interface.md)

Main chat area with streaming responses, message history, input field, and real-time updates. Includes progress indicators, clarification system, and query result visualization.

## Sidebar Navigation
Complete UI patterns: [sidebar-navigation.md](../../features/ui/sidebar-navigation.md)

Left sidebar with tabbed interface for conversation history and admin access. Includes conversation list, delete functionality, and relative date formatting.

## Admin Panel
Complete UI patterns: [admin-panel.md](../../features/ui/admin-panel.md)

Read-only conversation viewer for administrators to review all user conversations with full message history and user identification.

## Data Visualization
Complete UI patterns: [data-visualization.md](../../features/ui/data-visualization.md)

Intelligent chart generation for query results with auto-detection of chartable data. Supports bar, line, and pie charts with toggle visibility.

## Authentication Page
Complete UI patterns: [authentication-page.md](../../features/ui/authentication-page.md)

Login interface with email/password form, branded design, password visibility toggle, and comprehensive error handling.
