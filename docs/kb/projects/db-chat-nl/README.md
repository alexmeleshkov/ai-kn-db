# DB Chat NL - Natural Language Database Interface

A production-ready web application that allows users to query databases using natural language. Built with React, FastAPI, and Claude AI, featuring streaming responses, JWT authentication, and intelligent query learning.

## Quick Facts

- **Status**: Stable (Production deployment at https://www.itfcanalysis.com)
- **Stack**: React 18 + TypeScript + FastAPI + PostgreSQL
- **Key Technologies**: Claude Opus 4, Server-Sent Events (SSE), JWT + bcrypt, Chart.js
- **Architecture**: Layered monolith with separate frontend/backend
- **Deployment**: Heroku (Standard-2X dyno)

## Core Capabilities

Users can interact with databases through natural language:

1. **Natural Language to SQL** - Ask questions in plain English, get SQL queries generated by Claude AI
2. **Streaming Responses** - Real-time SSE streaming with heartbeat for long-running queries
3. **JWT Authentication** - Self-hosted authentication with bcrypt password hashing
4. **Chat History** - Persistent conversation storage with PostgreSQL
5. **Query Visualization** - Auto-generated charts (bar, line, pie) for query results
6. **Agentic Tool Use** - Claude uses tools (`execute_sql`, `ask_clarification`) for iterative refinement
7. **Extended Thinking** - Complex query analysis with 5000-token thinking budget
8. **Learning System** - Learns from successful queries to improve future accuracy
9. **Schema Viewer** - Browse database tables and columns
10. **CSV Export** - Download query results as CSV files

## Quick Start

```bash
# Backend setup
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env with your credentials

# Run backend
uvicorn app.main:app --reload

# Frontend setup (new terminal)
cd frontend
npm install
npm run dev
```
