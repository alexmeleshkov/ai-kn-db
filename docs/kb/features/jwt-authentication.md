# JWT Authentication

**Feature ID**: authentication.jwt-bcrypt
**Capability**: jwt-authentication
**Technologies**: fastapi, jwt-bcrypt, postgresql, react-hooks, typescript

---

## Overview

JWT-based authentication system with bcrypt password hashing, providing secure user registration, login, and session management. Implements stateless authentication using JSON Web Tokens with FastAPI backend and React hooks frontend.

**Key characteristics**:
- Stateless JWT authentication (no server-side session storage)
- bcrypt password hashing with automatic salt generation
- Token-based authorization with Bearer scheme
- Admin role flag in JWT payload for role-based access control
- Email validation using Pydantic EmailStr
- PostgreSQL persistence for user data
- React custom hook (useAuth) for frontend state management
- Password visibility toggle in login UI

## Implementation Patterns

### 1. Authentication Routes (auth_routes.py)

**Purpose**: FastAPI router implementing JWT-based authentication with register, login, logout, and user info endpoints

**Interface**:
```python
# Request/Response Models
class RegisterRequest(BaseModel):
    email: EmailStr
    password: str

class LoginRequest(BaseModel):
    email: EmailStr
    password: str

class AuthResponse(BaseModel):
    user: dict
    access_token: str

class UserResponse(BaseModel):
    id: str
    email: str
    is_admin: bool = False

# Dependencies
def get_auth() -> Optional[AuthService]
async def get_current_user(authorization: Optional[str] = Header(None), auth: Optional[AuthService] = Depends(get_auth)) -> dict

# Routes
@router.post("/auth/register", response_model=AuthResponse)
async def register(request: RegisterRequest, auth: Optional[AuthService] = Depends(get_auth))

@router.post("/auth/login", response_model=AuthResponse)
async def login(request: LoginRequest, auth: Optional[AuthService] = Depends(get_auth))

@router.post("/auth/logout", response_model=MessageResponse)
async def logout(current_user: dict = Depends(get_current_user))

@router.get("/auth/me", response_model=UserResponse)
async def get_me(current_user: dict = Depends(get_current_user))

@router.get("/auth/status")
async def auth_status(auth: Optional[AuthService] = Depends(get_auth))
```

**Complete Flow**:

1. **Register**:
   - Receive email + password in RegisterRequest
   - Check if AuthService is available (raise 503 if not)
   - Call auth.register(email, password)
   - If error in result dict, raise HTTPException 400 with error detail
   - Return AuthResponse with user dict and JWT access_token

2. **Login**:
   - Receive email + password in LoginRequest
   - Check if AuthService is available (raise 503 if not)
   - Call auth.login(email, password)
   - If error in result dict, raise HTTPException 401 with error detail
   - Return AuthResponse with user dict and JWT access_token

3. **Logout**:
   - Requires get_current_user dependency (validates JWT)
   - Return success message
   - Note: JWT is stateless, actual logout happens client-side by removing token

4. **Get Me**:
   - Requires get_current_user dependency (validates JWT and extracts payload)
   - Return UserResponse with id, email, is_admin from current_user dict

5. **get_current_user Dependency**:
   - Extract Authorization header from request
   - Validate header format: "Bearer <token>" (2 parts, first part is "bearer" case-insensitive)
   - Extract token from parts[1]
   - Verify token using auth.verify_token(token)
   - If invalid/expired, raise 401
   - Return dict with user_id, email, is_admin from JWT payload

**All Behaviors**:
- Email validation: Uses Pydantic EmailStr to validate email format in requests
- Password hashing: Passwords hashed by AuthService before storage
- JWT token generation: Tokens generated by AuthService and returned in AuthResponse
- Stateless logout: JWT tokens are not revoked server-side, client must discard token
- Bearer token extraction: Parses "Bearer <token>" format with case-insensitive "bearer" check
- Token verification: Delegates to AuthService.verify_token() for signature and expiration check
- is_admin flag: Extracted from JWT payload, defaults to False if not present
- Service availability: All routes check if AuthService is initialized before proceeding
- Error status codes: 400 for registration errors (duplicate email), 401 for login/auth failures, 503 for service unavailable

**Dependencies** (with WHY):
- fastapi (APIRouter, HTTPException, Depends, Header) - Web framework for routing and dependency injection
- pydantic (BaseModel, EmailStr) - Request/response validation and email format validation
- services.auth.get_auth_service - Retrieve initialized AuthService for registration, login, token verification
- Optional from typing - Handle case where AuthService may not be initialized or Authorization header missing

**Error Handling**:
- 503 Service Unavailable: If AuthService not initialized
- 401 Unauthorized: If Authorization header missing, malformed, token invalid/expired, or login credentials wrong
- 400 Bad Request: If registration fails (e.g., email already exists, password too weak)
- get_current_user raises 401 with specific messages:
  - "Authorization header required" if header missing
  - "Invalid authorization header format" if not "Bearer <token>" format
  - "Invalid or expired token" if token verification fails

**Integration Points**:
- Calls: AuthService.register(), AuthService.login(), AuthService.verify_token()
- Called by: Frontend AuthPage component, all authenticated endpoints via get_current_user dependency
- Data flow: Request → validation → AuthService → database → JWT generation → response

```python

# Usage Pattern:
```

### 2. Authentication Service (auth.py)

**Purpose**: JWT token creation/verification, bcrypt password hashing, user CRUD operations with PostgreSQL

**Interface**:
```python
class AuthService:
    def __init__(self, db_url: str, jwt_secret: str)
    def register(self, email: str, password: str) -> dict
    def login(self, email: str, password: str) -> dict
    def verify_token(self, token: str) -> Optional[dict]
    def _hash_password(self, password: str) -> str
    def _verify_password(self, password: str, hashed_password: str) -> bool
    def _create_access_token(self, data: dict) -> str
    def _get_user_by_email(self, email: str) -> Optional[User]
    def _create_user(self, email: str, hashed_password: str) -> User

def get_auth_service() -> Optional[AuthService]  # Singleton factory
```

**Complete Flow**:

1. **Register**:
   - Check if user with email already exists via _get_user_by_email()
   - If exists, return {"error": "User already exists"}
   - Hash password using _hash_password() (bcrypt with auto-generated salt)
   - Create user in database via _create_user()
   - Create JWT token with user_id, email, is_admin via _create_access_token()
   - Return {"user": {id, email, is_admin}, "access_token": jwt_token}

2. **Login**:
   - Find user by email via _get_user_by_email()
   - If not found, return {"error": "Invalid credentials"}
   - Verify password using _verify_password() (bcrypt.checkpw())
   - If password incorrect, return {"error": "Invalid credentials"}
   - Create JWT token with user_id, email, is_admin
   - Return {"user": {id, email, is_admin}, "access_token": jwt_token}

3. **Verify Token**:
   - Decode JWT using jwt.decode() with secret and HS256 algorithm
   - Extract user_id, email, is_admin from payload
   - Check expiration (exp claim)
   - Return dict with user_id, email, is_admin
   - On DecodeError or ExpiredSignatureError, return None

4. **Hash Password**:
   - Generate salt using bcrypt.gensalt()
   - Hash password using bcrypt.hashpw(password.encode(), salt)
   - Return base64 encoded hash string

5. **Verify Password**:
   - Decode stored hash from base64
   - Compare using bcrypt.checkpw(password.encode(), hashed)
   - Return True if match, False otherwise

6. **Create Access Token**:
   - Copy data dict (user_id, email, is_admin)
   - Add exp claim: datetime.utcnow() + timedelta(hours=24)
   - Encode using jwt.encode(payload, secret, algorithm="HS256")
   - Return JWT string

**All Behaviors**:
- Singleton pattern: get_auth_service() returns global _auth_service instance
- bcrypt salt generation: Automatic salt generated per password (not shared)
- JWT expiration: 24-hour token lifetime
- Password validation: Minimum 6 characters (enforced at route level via Pydantic)
- Email uniqueness: Checked before user creation, returns error if duplicate
- Constant-time comparison: bcrypt.checkpw() prevents timing attacks
- is_admin flag: Defaults to False for new users, can be set manually in database
- Database session management: SQLAlchemy session with commit/rollback
- Error propagation: Returns error dict instead of raising exceptions (caller decides on HTTP status)

**Dependencies** (with WHY):
- jwt (PyJWT) - JWT token encoding/decoding with HS256 algorithm
- bcrypt - Password hashing with automatic salt generation and timing-attack resistance
- sqlalchemy - ORM for database operations (User model, session management)
- psycopg2 - PostgreSQL driver (used by SQLAlchemy)
- datetime, timedelta - Token expiration calculation
- base64 - Hash encoding for database storage

**Error Handling**:
- Duplicate email: Returns {"error": "User already exists"}
- Invalid credentials: Returns {"error": "Invalid credentials"} (same message for user not found or wrong password)
- Invalid token: Returns None (caller raises 401)
- Expired token: Returns None (jwt.ExpiredSignatureError caught)
- Decode error: Returns None (jwt.DecodeError caught)
- Database errors: Caught in try/except, session rollback, error returned

**Integration Points**:
- Calls: SQLAlchemy User model, bcrypt, jwt
- Called by: auth_routes.py (register, login, verify_token), require_admin dependency
- Database: PostgreSQL users table (id, email, hashed_password, is_admin, created_at)
- Returns: dict with user data and token, or error dict

**Constants and Configuration**:
```python

JWT_ALGORITHM = "HS256"  # HMAC with SHA-256
TOKEN_EXPIRATION = timedelta(hours=24)  # 24-hour token lifetime
PASSWORD_MIN_LENGTH = 6  # Enforced at route level
```

**Module Exports**:
```python

def get_auth_service() -> Optional[AuthService]  # Singleton factory

# Usage Pattern:
# from .services.auth import get_auth_service

```

**Initialization Patterns**:
```python
# Singleton pattern with global variable
_auth_service: Optional[AuthService] = None

def get_auth_service() -> Optional[AuthService]:
    global _auth_service
    if _auth_service is None:
        jwt_secret = os.getenv("JWT_SECRET")
        database_url = os.getenv("DATABASE_URL")
        if jwt_secret and database_url:
            _auth_service = AuthService(database_url, jwt_secret)
    return _auth_service
```

### 3. User Model (database.py)

```python
class User(Base):

    id: Column(Integer, primary_key=True)
```

**All Behaviors**:
- Email uniqueness: Enforced by unique=True constraint at database level
- is_admin flag: Defaults to False, must be set manually for admin users
- created_at timestamp: Automatically set on user creation
- Password storage: Only stores bcrypt-hashed password (never plain text)
- Cascade delete: Conversations deleted when user deleted (via relationship)

**Integration Points**:
- Used by: AuthService for user CRUD operations
- Related to: Conversation model (one-to-many relationship)

**Complete Flow**:

**All Behaviors**:

## Security Considerations

### Password Security
- bcrypt hashing with automatic salt generation (prevents rainbow table attacks)
- Constant-time password comparison (prevents timing attacks)
- Minimum 6-character password requirement
- Passwords never stored in plain text
- Passwords never logged or returned in API responses

### JWT Security
- HS256 algorithm (HMAC with SHA-256)
- 24-hour token expiration
- Secret key stored in environment variable (not in code)
- Token signature verification on every request
- is_admin flag in JWT payload (cannot be forged without secret)

### API Security
- Email uniqueness enforced at database level (prevents duplicate accounts)
- Same error message for "user not found" and "wrong password" (prevents email enumeration)
- Authorization header required for protected endpoints
- Bearer token format enforced
- 401 for missing/invalid tokens, 403 for insufficient permissions

### Frontend Security
- Password visibility toggle (UX without compromising security)
- HTTPS recommended for production (prevents token interception)
- JWT stored in localStorage (accessible to JavaScript, consider httpOnly cookies for higher security)
- Automatic redirect to login on 401 responses

## Testing Patterns

### Unit Tests (Backend)

**Test register with duplicate email**:
```python
def test_register_duplicate_email():
    auth = AuthService(db_url, jwt_secret)
    auth.register("test@example.com", "password123")
    result = auth.register("test@example.com", "password456")
    assert "error" in result
    assert result["error"] == "User already exists"
```

**Test login with wrong password**:
```python
def test_login_wrong_password():
    auth = AuthService(db_url, jwt_secret)
    auth.register("test@example.com", "correct_password")
    result = auth.login("test@example.com", "wrong_password")
    assert "error" in result
    assert result["error"] == "Invalid credentials"
```

**Test JWT token expiration**:
```python
def test_token_expiration():
    auth = AuthService(db_url, jwt_secret)
    # Create token with past expiration
    expired_token = jwt.encode(
        {"user_id": 1, "exp": datetime.utcnow() - timedelta(hours=1)},
        jwt_secret,
        algorithm="HS256"
    )
    result = auth.verify_token(expired_token)
    assert result is None
```

### Integration Tests

```python
async def test_registration_login_flow():
```
